# Luxury Car Dealership 🚗

A full-stack web application for a luxury car dealership, showcasing modern web development practices and containerization.

## 🛠️ Tech Stack
- Frontend React, TypeScript, TailwindCSS, Vite
- Backend Node.js, Express.js, RESTful API
- Infrastructure Docker, Docker Compose

## ✨ Features
- Modern, responsive UI designed with TailwindCSS.
- Dynamic rendering of vehicle inventory from a REST API.
- Fully containerized environment for consistent development and deployment.

## 🚀 How to Run

### Method 1 Using Docker (Recommended)
1. Ensure Docker Desktop is installed and running on your machine.
2. Open your terminal in the root directory of the project.
